# 小猫知识库

所有资料统一存放在本目录。原 `skills` 的分类、正式 `SKILL.md`、原书和辅助资料已完整迁入，项目只使用 `knowledge` 一个知识目录。

## 添加资料

在本目录中建立任意分类文件夹，再创建 `.md` 文件。普通标题加正文就能使用，不要求特定文件名，也不用修改 registry.json 或代码。

可以复制 `_templates/知识条目.md` 到分类目录，改成自己的文件名，填好正文并将 `enabled` 改为 `true`。

可选的顶部字段：

- `title`：显示标题。
- `description`：简短摘要，便于目录展示和检索。
- `enabled`：设为 `false` 暂停该文件，省略时默认启用。
- `tags`：主题标签。
- `keywords`：完整关键词、术语或同义表达，优先用于检索，例如 `[激励机制, 利益冲突, 绩效考核]`。
- `triggers`：常见提问或适用场景，例如 `[为什么制度改了但行为没变]`；这是检索线索，不会执行动作。
- `source`、`updated`：来源与更新时间，随选中正文一起提供给 LLM。

这些字段也适用于旧的 SKILL.md。正文按知识资料提供，文件中出现的“执行步骤”不会变成程序工具。

## 更新与检索

`registry.json` 是程序自动维护的完整知识索引，保存路径、标题、摘要、检索关键词、正文长度、启用状态、内容指纹及文件状态。`entries` 是全部候选知识条目的索引；`sources` 保留原资料包的来源信息，不用于限制加载范围。

`keywords` 保存为可读的数组，每条最多 16 个完整词语或短语。优先采用正文顶部的 `keywords`、`tags`、短 `triggers`，不足时用本地中文词典从标题和摘要补充；不会再把全文机械切成两三个字的片段。纯数字、日期、版本号、通用词不进入关键词。未填写摘要时，使用正文开头最多 240 字作为摘要。`triggers` 最多保留 8 条场景。

匹配结合完整关键词、标题和摘要；摘要中单个偶然重合的词不足以选中文章，“不适用于”之后的说明不作为正向线索。“失败、风险、压力、情绪”等宽泛词只辅助排序，不能单独让条目入选。中文短语也检查词边界，例如“数据”不会命中“数据库”中的部分文字。

`triggers` 可填写完整的典型情境。检索会逐条比较场景，至少命中两个有辨识度的词，并覆盖问题与该场景中各至少一半的有效词，才将改写的问题视为场景匹配；不同场景的零散词不会拼在一起算命中。同义说法可补入 `keywords`，场景换一种常见说法时可补入 `triggers`，修改 Markdown 后索引自动更新。

近期对话用于补充明确的追问，切换话题时不会仅因旧话题命中而附送旧资料。匹配在本地完成，仍属于词语与场景检索，不会调用额外的 LLM，也不能保证理解所有同义表达。

项目根目录运行 `python scripts/check_knowledge_triggers.py` 可复测真实知识库的常见问题和负例，结果保存到 `tests/knowledge_trigger_report.json`。测试检查实际请求中的正文，API 使用模拟响应，不会产生外部模型调用。

第一次运行或索引缺失、损坏时读取正文建立索引。此后每次提问先读索引，并检查文件列表、修改时间和大小等状态，只重新解析新增或修改的文件，删除的文件自动移出索引。普通编辑、新建、删除、启用和停用都会在下一次提问生效；检索完成后，仅打开选中的文件读取正文。文件完全未变时不重复写索引。

索引无需手动维护，也不要手动修改其中的元数据。需要强制重建时删除 `registry.json` 即可，下次提问自动重建（请先保留其中需要的来源记录）。如果目录不可写，程序使用内存索引；重启后需要重新建立。通过特殊工具修改正文并同时保留所有文件状态时，也应手动重建。

每次提供全部启用条目的目录，并根据当前问题和近期用户消息最多选择 6 份相关正文；正文总计不超过 32,000 字符。较长资料建议按独立主题拆分成多个文件，超过正文预算的整篇资料不会附送。

相同文件内容（忽略行尾空白）只收录一次，按文件路径排序保留第一份。不同版本或不同表述不会自动合并，以免丢失内容。

只检索 Markdown 文件。README.md、INDEX.md、LICENSE.md、BOOK_OVERVIEW.md、DIGEST.md、GLOSSARY.md、verified.md、PIPELINE_STATE.md 是保留的辅助文件名，不参与检索；以 `_` 或 `.` 开头的文件或目录以及 tests、rejected、candidates 目录也不参与检索。原书、测试和草稿仍保留在原分类中。

安装版可在 StockPet.exe 同级建立 knowledge 目录，自行维护；该目录存在时优先使用它，否则读取打包的知识目录。
