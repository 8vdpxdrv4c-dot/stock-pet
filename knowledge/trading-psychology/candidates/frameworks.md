# 框架候选提取（Framework Extractor）

> 来源：《投资交易心理分析》(Brett N. Steenbarger)
> 提取器：框架提取器
> 提取规则：思维模型 / 决策框架 / 推理方法；仅保留可应用于交易执行、复盘、状态管理、市场解读的框架。

- id: f01
  title: 靠在沙发上进行交易（把自己当作市场数据）
  type: framework
  source_chapter: 前言
  source_quote: |
    "我把这种方法称为'靠在沙发上进行交易'，即充分利用你的思维、情感、冲动以及行为模式，将其视为市场数据。"
  summary: |
    全书的总框架：交易者不再把情绪当作需要克服的敌人，而是当作像价格、成交量一样的市场数据来读取。
    既然情绪是数据，那它就有信息含量：恐惧/贪婪/冲动都指向市场的某种状态，也指向自己处理信息的模式。
    你既是交易者又是自己的心理医生，观察的对象从"市场在做什么"扩展到"我在做什么、我此刻处于什么状态"。
    这一框架为后面的内部观察员、情绪温度测量、多自我等具体方法提供了统一的视角。
  tags: [mental-model, self-observation]

- id: f02
  title: 问题即失效的解决方案
  type: framework
  source_chapter: 第 1 章
  source_quote: |
    "本书将反复探讨这个主题：问题是失效的解决方案。问题就是在人生某个阶段某种情绪下学会的而现在本身又成为问题的解决模式。"
  summary: |
    核心心智模型：一个反复出现的"问题行为"（如追涨杀跌、扛单），本质上是某个过去情境下曾经有效的解决方案，只是今天失效了。
    因此治疗/改进的方向不是"消灭坏行为"，而是把旧方案替换成新的方案。
    对交易者的含义：亏钱模式（如牛市里学会的逢跌就买）源于对旧行情的适应性反应，行情切换后它从优势变成了缺陷。
    识别"这个模式当初是为解决什么问题而学会的"，才能找到替代它的新方案，而不是空喊"我要纪律"。
  tags: [mental-model, change, trading-pattern]

- id: f03
  title: 聚焦解决方案：从特例中找成功模板
  type: framework
  source_chapter: 第 1 章
  source_quote: |
    "重视解决方案的策略之所以有效，是因为它将人的现有勇气作为杠杆，用它来轻松解决原本难以解决的问题。"
  summary: |
    推理方法：与其穷究"我为什么总是亏损"，不如去寻找"我在哪些时刻其实做得很好"——即问题模式中的例外。
    对交易者：翻看自己的交易记录，找出少数赚了钱、执行得很漂亮的交易，分析当时的状态、时机和方法。
    这些"例外时刻"说明成功的能力已经存在，只是不稳定、没被系统化；把例外提炼成可重复的模板，比克服缺陷更快。
    与"问题即失效的解决方案"配套：一个聚焦问题，一个聚焦例外，合起来构成完整的改进路径。
  tags: [reasoning, trading-review, solution-focused]

- id: f04
  title: 大无畏的交易清单 / 一致性复盘
  type: framework
  source_chapter: 第 1 章
  source_quote: |
    "检查你的交易模式：失败时，你做错了什么？成功时，你做对了什么？每个模式都有一个目的：让你更好地了解自己的交易，认识你自己。"
  summary: |
    决策框架：像做诚实体检一样，逐笔审查自己的每一笔交易，不回避失败、不美化成功，找出跨交易的一致模式。
    关键动作：对成功交易和失败交易分别提问"我当时做对了/做错了什么"，把答案归纳为几条稳定的行为模式。
    用途是"认识自己"而非"审判自己"——目标是从数据中提取模式，为后面锁定需要改变的具体行为提供依据。
    这是把交易心理从玄学变成可操作复盘的第一步，也是全书反复回扣的基础工具。
  tags: [decision, trading-review]

- id: f05
  title: 改变风险-回报等式（重新定义成败）
  type: framework
  source_chapter: 第 2 章
  source_quote: |
    "每个重大的改变必然会引起视角的变化以及对风险和回报的重新定义。"
  summary: |
    决策框架：一个人不愿改变，往往是因为在当前的等式里"改变的成本/风险 > 维持原状的回报"；改变的钥匙是重构这个等式。
    对交易者：例如把"止损=承认失败"重新定义为"止损=保留本金、马上有下一次机会"，把"扛单=有希望"重新定义为"扛单=确定性亏损"。
    当风险与回报的定义被翻转，原本难以执行的纪律（止损、减仓）会变得顺理成章。
    框架的操作路径：找出卡住自己的行为 → 问"按当前定义，我得到了什么、付出了什么" → 换一套更符合长期目标的定义。
  tags: [decision, risk-management, reframing]

- id: f06
  title: 大声说出交易计划（说出口即客观化）
  type: framework
  source_chapter: 第 2 章
  source_quote: |
    "自己跟自己说出交易计划时，你一人分饰两角……一旦你把交易计划说出来，许多内容就会留在你的脑海里。"
  summary: |
    决策框架：开市前把当天交易计划用平时说话的声音大声说出来，仿佛在评论另一个人，而不是默看报表。
    说出口迫使你脱离"内心里模糊的冲动"，把计划变成可被自己听见、被自己审查的客观对象。
    效果：能提前暴露计划中的漏洞（"那不在我的交易计划之列！"），也能让计划真正留在脑海里供执行时核对。
    本质是把内部自我对话外部化，让"分析的自我"与"执行的自我"在开市前就对齐，减少盘中临时起意。
  tags: [decision, trading-execution, self-talk]

- id: f07
  title: 内部观察员（冷静旁观的自我）
  type: framework
  source_chapter: 第 3 章
  source_quote: |
    "内部观察员是自我的一部分，它不受情绪的影响，冷静地观察着一切。"
  summary: |
    心智模型：在"正在交易的你"之外，训练出一个"观察你在交易的你"——它不被涨跌刺激，只记录发生了什么、你感觉如何、你正在按什么模式行动。
    激活方法：深呼吸 + 越过厌倦极限（坚持观察已到极限后继续观察），相当于给意识做个冷启动。
    对交易者的应用：当情绪（兴奋/恐惧）达到顶点时，内部观察员是你唯一能保持客观、阻止冲动下单的部分。
    它是"情绪温度测量"、"多自我识别"等框架的共同地基：先有旁观，才有测量与管理。
  tags: [mental-model, self-observation, trading-state]

- id: f08
  title: 情绪即数据：逆向使用情绪信号
  type: framework
  source_chapter: 第 3 章
  source_quote: |
    "在这种时候，我会把情绪当作重新研究的线索，查询数据库并找到最近几次类似的抛售行情，看看后市都发生了什么。"
  summary: |
    推理方法：不把情绪当噪音，而把它当成关于市场的反向信息——你自己的恐惧与贪婪，往往正是市场拐点的领先指标。
    具体路径：感到恐慌 → 不去平仓或追空，而是把恐慌当作"市场可能过度反应"的信号，去研究历史类似情境的后市。
    过度自信 = 减仓/谨慎信号；普遍恐慌 = 潜在反弹机会。情绪反应的强度与市场极端程度成正比。
    核心是先暂停行动、把情绪翻译成研究问题，再决定交易，形成"情绪→研究→行动"而不是"情绪→行动"的回路。
  tags: [reasoning, market-reading, emotional-signal]

- id: f09
  title: 情绪温度测量：状态不对不交易
  type: framework
  source_chapter: 第 3 章
  source_quote: |
    "一旦你注意到自己的认知、身体和情绪状态，根据医生的信条，你的首要目标就是'无论如何，避免伤害'。如果你觉得无聊，情绪低落，那么不要交易。"
  summary: |
    决策框架：交易前/交易中定期给自己的情绪状态打分（激发程度与效价两个维度），把它当作是否交易的闸门。
    规则是"先无害，再盈利"：无聊、情绪低落、过度兴奋、沮丧时，一律不交易或先缩小仓位。
    它把"情绪管理"变成可操作的自检清单：测量 → 判断状态是否适合交易 → 不合适就退出/暂停。
    与内部观察员配套：先有旁观者才能测量；与"停下练习"配套：用闹钟提醒自己周期性测量。
  tags: [decision, trading-state, execution-discipline]

- id: f10
  title: 压力预防：在脑海中放电影（预演最坏情境）
  type: framework
  source_chapter: 第 3 章
  source_quote: |
    "目标就是：在真正入市交易前，做到可以在脑海中多次播放电影而无须任何停顿。"
  summary: |
    决策框架：入市前在脑海里反复预演可能发生的交易情境（尤其最坏的：止损被触发、暴跌、被套），直到能流畅播放而不起应激反应。
    预演时一旦感到不适，就暂停、深呼吸、平静后继续，直到整部"电影"可以无停顿播完。
    原理是压力预防：真实情境到来时，反应已经排练过，情绪强度大幅降低，你就能按计划执行而不是被情绪劫持。
    它把"临场应变"前移到"事前彩排"，是执行纪律与止损执行力的基础训练。
  tags: [decision, rehearsal, execution-discipline]

- id: f11
  title: 多自我：现在是哪个我在交易？
  type: framework
  source_chapter: 第 4 章
  source_quote: |
    "在市场中，人们之所以会交易失败，是因为决定交易和管理退出交易的不是同一个人。也就是说，另一个自己（也就是另一种思维）出现了。"
  summary: |
    心智模型：大脑有多个半独立的"自我"（语言理性型 + 情绪身体型等），交易失败常常是"下单的自我"与"止损的自我"根本不是同一个。
    使用方式：每笔交易问"现在是哪个我在做决策？这个我是想盈利的分析者，还是想证明自己、发泄情绪的另一个我？"
    配套做法：记录每笔交易时的心理状态，事后归因于具体"自我"，识别出常失控的那个自我及其触发条件。
    它解释了"计划做得很好但执行时全变样"，也为"交易教练""理想自我"等框架提供了存在论前提。
  tags: [mental-model, trading-state, self-observation]

- id: f12
  title: 元信息传递：读市场"怎么走"而不是"走到哪"
  type: framework
  source_chapter: 第 6、8 章
  source_quote: |
    "这种元信息传递被称为标记，因为它们标志着从一种认知或心理状态到另一种状态的转换点。标记对于交易者们来说也是重要的指示。"
  summary: |
    心智模型：市场每时每刻发两类信息——内容（涨到多少点）和元信息（怎么涨上去的：一气呵成还是反复犹豫、放量还是缩量、普涨还是分化）。
    元信息即市场的"语气/身体语言"，它揭示了参与者的情绪状态：犹豫、恐慌、贪婪、坚定。
    交易应用：关注相对成交量、TICK、板块齐涨齐跌等"标记"，把每一次元信息的改变当作状态切换点，而不是只看点位。
    类似心理治疗中语调、语速、姿势的变化预告主题切换，市场元信息预告行情性质的切换（趋势延续 vs 反转）。
  tags: [mental-model, market-reading, meta-communication]

- id: f13
  title: 隐性知识 → 显性规则（内隐学习）
  type: framework
  source_chapter: 第 6、14 章
  source_quote: |
    "当交易者能够将他们感觉到的认识转化为系统化的交易规则时，他们既保留了主观认识的价值，同时又与引起分心和曲解的情感反应保持了一定的距离。"
  summary: |
    推理方法：长期浸入市场后，交易者会先于语言形成对模式的"直觉/隐性知识"；把它翻译成可写下的显性规则，才能稳定复制。
    内隐学习需要大量密集试验（书引研究：1000次以上）+ 快速准确反馈 + 高度专注，短线高频交易者天然符合这些条件。
    对交易者的含义：多复盘历史图表、多做模拟试验来加速内隐学习；把直觉翻译成规则时，就与情绪化冲动拉开了距离。
    同时警示：规则过简则失真、过繁则妨碍内隐学习，交易者时间框架决定隐性/显性知识的相对权重。
  tags: [reasoning, implicit-knowledge, trading-learning]

- id: f14
  title: 新意 → 改变 → 巩固（在独特状态中重复）
  type: framework
  source_chapter: 第 7 章
  source_quote: |
    "要想发生实实在在的改变，一定要进行巩固。一个新的模式在真正内化之前，要经过多次的重复。如果没有巩固的过程，人们就容易回到以前的方式。"
  summary: |
    心智模型：改变分三步——新意（引入新体验/新认知）→ 改变（旧模式被替换）→ 巩固（新模式在独特状态中反复重复，直到自动化）。
    关键的陷阱在第 3 步：大多数人看到一点成效就停止练习，于是退回旧模式（书中引研究：疗效后退步率约 75%）。
    对交易者的应用：新策略要"每天以同样方式、在同一时间和环境下重复"，直到它变成自动反应、内化为自己的一部分。
    配套工具：磁场中心/停下练习——用固定信号（如闹钟、笔记本）周期性地把自己从旧模式中"叫醒"。
  tags: [mental-model, change, consolidation]

- id: f15
  title: 状态换挡：环境 / 姿势 / 音乐 / 枢纽和弦
  type: framework
  source_chapter: 第 2、9、13 章
  source_quote: |
    "转换环境是形成新心境最简单、最强有力的方式之一。大多数人会随着环境的变化而产生不同的意识状态。"
  summary: |
    推理方法：与其在同一个状态里跟情绪硬扛，不如物理性地改变状态载体——环境、坐姿、音乐、动作、说话节奏。
    具体手段：离开交易屏幕、站起走动、播放大音量音乐并摆动身体、换个椅子（书中埃里克的例子：换个座位即转好交易）、改变语气节奏。
    "枢纽和弦"是状态转换的触发点：在情绪最激动处，用一个出其不意的节奏/隐喻把心念转向新方向。
    原理：状态（情绪+生理+认知的组合）决定信息处理方式，换挡即换处理方式，从而打破"状态→旧模式"的循环。
  tags: [reasoning, trading-state, state-shift]

- id: f16
  title: 触发器识别 → 消极自我对话 → 交易教练
  type: framework
  source_chapter: 第 10 章
  source_quote: |
    "许多时候，你不能识别哪些触发器在起作用，但却可以认清紧随其后的消极的自我对话……辨识出磁带的内容是你抛开它们的第一步。"
  summary: |
    决策框架：破坏性行为通常由"触发器→消极自我对话→错误行动"三步组成；干预从识别第一步开始。
    第一步：找出激活坏模式的触发器（如：连续亏损、错过机会、持仓过重）；第二步：辨识随之自动播放的消极自我对话（"我总是不行""又要爆仓了"）。
    第三步：用"交易教练"技巧打断——想象自己是教练，对那个初学交易者（你自己）说话，把消极磁带替换成有建设性的指导。
    这一链条把"我要改变"落成三个可执行的动作：识别触发、点名磁带、以教练身份替换。
  tags: [decision, trigger-identification, self-talk]

- id: f17
  title: 弹球窍门 / 逆向交易
  type: framework
  source_chapter: 第 11 章
  source_quote: |
    "像弹球游戏一样，你只有采取逆向思维策略，才能找到窍门。市场最疲软的时候买进，最强盛的时候卖出。"
  summary: |
    推理方法：市场像被设计过的弹球机，设计者的规则（顺势、追热点）保证玩家不赢钱；找到"规则之外"的概率优势，就是窍门。
    对交易者：不按大众共识出牌——在市场最疲软/恐慌时寻找买点，在最狂热/拥挤时警惕卖点；识别"失败的突破"等逆向信号。
    窍门一旦找到，就是可以反复使用、带来统计优势的重复模式，而不是一次性运气。
    配套思路：市场过度反应是常态，逆向交易利用的正是"情绪极端=反转概率上升"。
  tags: [reasoning, market-reading, contrarian]

- id: f18
  title: 交易即预测：每笔交易都是一个假设（先锋头寸）
  type: framework
  source_chapter: 第 11 章
  source_quote: |
    "如果你把每一笔交易都看作对市场方向的预测……那么在预测被推翻的时候，所有的交易都该止损出局。"
  summary: |
    决策框架：把每笔交易写成显式假设——"在 X、Y、Z 条件下，我预测市场在 B 时段出现 A 情况"——市场验证则持有，被推翻则止损。
    好处：止损不再是"认输"，而是"假设被证伪，退场等下一个假设"，执行阻力大幅下降。
    配套仓位方法（先锋头寸）：先用小额头寸投石问路"勘察地形"，验证正确再追加；用仓位控制假设的不确定性风险。
    它把"盈亏"的叙事替换成"假设检验"，让交易者保持科学家的冷静与纪律。
  tags: [decision, hypothesis-testing, risk-management]

- id: f19
  title: 市场 = 投射测试（罗夏墨迹）：读评论者的情绪化语言
  type: framework
  source_chapter: 第 11 章
  source_quote: |

  title: 危机作为催化剂 / 跳跃：彻底改变行为
  type: framework
  source_chapter: 第 12 章

  summary: |
    心智模型：巨大的压力/亏损/危机反而打开信息之门，让人在强烈情绪下更真实地看到自己，并做出平时做不到的彻底改变。
    配套行动（跳跃）：想要加快改变，就不只是"做点不一样的事"，而是彻底跳到一种全新的行为模式/生活方式中。
    对交易者的应用：在亏损危机中的人最有改变动力；改变手段可以是彻底的低频交易、严苛的资金规则、离开屏幕重新系统化。
    原理：常规状态维持常规行为，唯有跳出常规状态（危机或极端手段），新模式才有立足之地。

- id: f21
  title: 愤怒作为同盟："去你的"疗法
  type: framework
  source_chapter: 第 13 章
  source_quote: |
    "不用把怒气发泄到自己身上或者周围的环境中，可以把怒气发泄到自己的问题模式上。事实上，对这些模式生气，是让自己脱离它们并保持观察者的姿态的重要一步。"
  summary: |
    推理方法：把自我攻击的能量改道——不对自己发火（"我真没用"），而对自己的问题模式发火（"这个模式给我带来太多亏损，去你的"）。
    愤怒在这里被当作切断消极自我对话、跳出自我贬低循环的燃料，把"我是失败者"改写成"我 vs 我的坏模式"。
    对交易者：在完美主义、自责式复盘造成的瘫痪中，用这种外化的愤怒重新站起来，把力量指向需要改变的行为而非自我。
    原则是"对事不对己"：愤怒指向模式，观察者姿态得以保持，行动力反而增强。

- id: f22
  title: 三类转换策略（抑制 / 跳跃 / 培养）
  type: framework
  source_chapter: 第 14 章
  source_quote: |
    "你可以尝试抑制有害的反应，跳跃到不同的状态和模式，或者培养新的积极的状态和模式。"
  summary: |
    决策框架：所有交易心理转换可以归入三大策略，按情况选用——
    ① 抑制：识别触发情绪反应的环境，用冥想/枯燥动作（如弹手指）压制侵入型情绪反应，冷静处理止损等情境。
    ② 跳跃：当状态被压制/枯竭时，彻底换挡到另一种生理-情绪状态（如离开屏幕做强度运动），离开原状态再处理信息。
    ③ 培养：从交易日志中找出"正确执行的交易"，把成功模式固定在独特状态中反复预演，直到内化。
    选择依据：抑制型问题（焦虑/恐慌）用①③，激发型问题（冲动交易）用②③；所有策略成败取决于复盘的深度与预演的次数。
  tags: [decision, change, trading-state]

- id: f23
  title: 交易与性格匹配（方法必须适合人）
  type: framework
  source_chapter: 第 14 章
  source_quote: |
    "问题不是哪种交易方式最好，重要的是交易方法要适合交易者。"
  summary: |
    决策框架：先诊断自己的性格与认知风格（风险承受度、视觉直觉型还是规则型、冲动程度），再选择与之匹配的交易方法。
    反例警告：直觉型交易者强行套机械系统、长线思维者强做高频、低风险承受者持重仓，都会以"情绪问题"的形式爆发。
    因此很多"情绪问题"其实是"结构问题"：交易没构建好（缺乏明确入退场触发与资金管理），才显得情绪化。
    排查顺序：情绪痛苦严重/易冲动/尽责性低的人先评估是否适合交易；适合者把方法限制在一两种经验证的模式上，忠实执行。
  tags: [decision, self-assessment, trading-style]
