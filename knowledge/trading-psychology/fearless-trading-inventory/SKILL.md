# 大无畏的交易清单 / 一致性复盘

## R — 原文 (Reading)

> 要想在市场游戏中升级，我只有列出自己大无畏的交易清单。因此，我对以前的交易进行了反思，一个接一个，既有成功的也有失败的。我不停地寻找着模式：成功的交易有什么共性？失败的交易有何重复因素？结果惨不忍睹，但意义深远。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第1章

> 交易日志应该包括交易操作、交易原理、利润目标、止损参数、交易心态以及交易结果。每周你都应该给自己打分，看看自己到底怎样遵循了交易计划；每周你都需要对自己交易的一致性进行回顾。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第1章

---

## I — 方法论骨架 (Interpretation)

交易者失败，常常不是方法不对，而是执行不一致：同一个人在不同心态下，把同一套规则执行成完全不同的结果。

"大无畏的交易清单"是这样一种复盘仪式：像嗜酒者互诫协会公开承认"我是酒鬼"一样，鼓起勇气一次性地、不回避失败地回顾自己的全部交易历史，然后逐笔对照成功与失败交易，寻找跨交易的一贯模式——成功交易有什么共性、失败交易有什么重复因素。

作者用这套清单发现自己的问题归结为一个词：**一致性**。失败集中在五个维度前后不一——持仓量、交易准备、执行方式、交易角度、清仓方案。

配套机制是六要素交易日志（操作、原理、利润目标、止损参数、心态、结果）+ 每周给"遵循计划的程度"打分。复盘的着眼点不是盈亏，而是"是否准备充分、是否按计划执行"——把一致性从模糊概念变成可测量的行为。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者自己的"五不一"复盘
- **问题**: 拥有双学位、顶级数据工具、多年研究，却持续亏钱。
- **方法论的使用**: 用大无畏清单逐笔回顾全部交易，不寻找新指标而是寻找"一致模式"。
- **结论**: 发现成功与失败交易使用的市场指标几乎相同——差异全在一致性：连胜后加大仓位、亏损交易多是冲动、止损后短单变长单。
- **结果**: 从此"很少再出现大额亏损"，清单演化为其交易执行框架的基础。

### 案例 2: 64位交易者的NEO人格调查
- **问题**: 什么样的心理特质区分成功与失败交易者？
- **方法论的使用**: 对64位交易者施测人格问卷，对照其交易表现。
- **结论**: 最成功的交易者在"尽责性"上得分高——稳定、可靠、有纪律；问题交易者在"神经性/开放性"上得分高。
- **结果**: 佐证"交易复盘记录 + 计划执行 + 一致性"本质是尽责性的交易化表达。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 连续亏损、或"稳定小亏"，却说不出明确原因。
2. 想系统性地复盘自己的交易历史，但不知道从哪里下手。
3. 写了交易日志但只记了盈亏，没有记录决策过程和心态。
4. 被问到"你最大的交易错误是什么"答不上来，或归因于"心态不好""运气差"。
5. 想建立每周/每月的复盘仪式，把交易从凭感觉变成按清单。

### 语言信号 (用户的话里出现这些就应激活)

- "帮我复盘一下我的交易"
- "为什么我总是一赚钱就亏回去"
- "我有交易记录，帮我分析"
- "我的交易不太一致/纪律差"
- "trade review" / "why do I keep losing" / "my trading is inconsistent" / "review my journal"

### 与相邻 skill 的区分

- 与 `solution-focused-trading`：**本 skill 找"不一致的缺口"**（哪里前后不一），后者**找"例外成功时刻"**（哪里做对了可放大）。复盘时先跑本清单找缺口，再从中提取例外。
- 与 `stop-loss-discipline`：本 skill 是**复盘机制**（如何审查历史），后者是**止损规则本身**（价格/指标/时间三分法）。本 skill 发现"止损总是不一致"时，组合后者落地。
- 与 `trading-plan-anchor`：本 skill 审查**历史执行**，后者设计**未来计划**（说出来/假设检验/先锋头寸）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **收集全部交易记录**
   - 让用户提供一段时间内的所有交易（成功与失败都要），若无书面记录则按记忆逐笔口述，标记可信度。
   - 完成标准: 至少有 10 笔以上交易，且成功与失败均有覆盖。

2. **逐笔对照，寻找五个维度的一致/不一致**
   - 对每笔交易追问: ①持仓量大小与近期盈亏是否相关？②准备是否充分（研究/演练 vs 临时起意）？③执行是否按计划（入场/止损/止盈）？④交易角度是否一致（短线/波段/是否偏离系统）？⑤清仓方案是否一致（止损后是否又变成长线）？
   - 完成标准: 写出 2–5 条明确的行为模式（如"连胜后自动加仓""亏损交易多为冲动入场"）。
   - 判停条件: 若用户交易记录不足 10 笔 → 跳到步骤 3 只建立日志机制，设定"两周后回来复盘"。

3. **建立六要素日志 + 每周一致性打分**
   - 日志六要素: 交易操作、交易原理、利润目标、止损参数、交易心态、交易结果。
   - 每周给"遵循计划程度"打 1–5 分，并回顾一致性。
   - 完成标准: 用户明确下周要记录什么、每周何时打分，且能复述自己发现的那条核心不一致模式。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有任何交易历史/数据，直接要建议（先建立日志再说）。
- 用户在问具体的买卖点或策略有效性（那是市场分析方法论，不是复盘）。
- 用户处于急性危机（刚爆仓、抑郁倾向）——先稳定，再复盘。

### 作者在书中警告的失败模式

- **工具与智力无法替代一致性**（ce02）：顶级工具+高智商，执行不一致照样亏。复盘不能只加指标，必须审视执行。
- **情绪化时规则最易被遗忘**（ce08）：情绪一起，规则就被抛到脑后。清单的意义在于把规则外部化。
- **记忆不可靠**（c19 加扎尼加）：事后回忆的"当时为什么买"往往是解释器编造的故事——必须靠日志而非回忆。

### 作者的盲点 / 时代局限

- 案例主要来自主动求助的交易者（求助者偏差），复盘对"从不记录的人"落地成本高。
- 2002年初版时代无高频算法市场；"一致性"在人工执行场景最有效，量化/程序化交易者的"一致性"问题形态不同。
- 复盘本身不产生优势——它只是防止执行劣化；若无正期望方法，再一致也是稳定亏钱。

### 容易混淆的邻近方法论

- "记交易日记"的常识——关键不是记录，而是**从记录中提取模式并量化打分**，否则只是记账。
- "复盘=找错误"——本 skill 是找**模式**（含成功的共性），不是自我审判。
