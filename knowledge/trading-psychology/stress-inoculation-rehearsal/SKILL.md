# 压力预防：在脑海中放电影

## R — 原文 (Reading)

> 开市前，在脑海里预演可能遇到的交易情境，你就可以做到一定程度的压力预防。你闭上眼睛，集中精神，慢慢地深呼吸，然后在脑海里放电影。……目标就是：在真正入市交易前，做到可以在脑海中多次播放电影而无须任何停顿。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第3章

> 他将这种方法称为压力预防，其工作原理是医学免疫。医生为病人接种疫苗预防疾病时，需要将少量病毒注入病人的血管，来激活病人体内的自然免疫反应。同样，你可以接种少量压力疫苗来激活理想的处理反应，以应对未来的交易挑战。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第3章

## I — 方法论骨架 (Interpretation)

交易者最怕的场景（止损被触发、隔夜持仓、市场暴跌、重仓被套）在真正来临时往往让人大脑一片空白、行为失序。压力预防的思路是**把恐惧源提前在脑海里演习到脱敏**，像疫苗一样让免疫系统提前认识病原体。

操作：开市前闭眼、深呼吸，在脑海中生动地"放电影"——预演可能遇到的交易情境、面对时的情绪反应、以及你打算如何处理（尤其是最坏的：止损被触发、暴跌、被套）。预演时一旦感到不适，就暂停、深呼吸、平静后继续，直到整部"电影"能无停顿地完整播放。

原理是反条件反射：在可控的身心状态下反复预演担心的情境，真实情境到来时，反应已经排练过，情绪强度大幅降低，你就能按计划执行而不是被情绪劫持。

作者强调：他大部分成功的交易以预演消极假设情境开始（在脑海中过一遍止损策略）；最糟糕的交易以粗略估算潜在利润开始。效果取决于使用频度与强度——浅尝辄止无法突破。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者的缆车恐高——责任压过恐惧
- **问题**: 作者本人严重恐高，带小男孩麦克雷坐滑雪缆车时满心恐惧。
- **方法论的使用**: 意识到不能让恐惧显现吓到孩子，用"照顾孩子的责任"迫使自己进入平静状态，把注意力转向照顾行动。
- **结论**: 这次"活体暴露"意外地大幅缓解了他的恐高——在受控/高动机场景中暴露于恐惧源可削弱条件反射。
- **结果**: 恐高症自此缓解，恐惧的条件反射被平静状态覆盖。

### 案例 2: 艾丽斯的渐进暴露
- **问题**: 创伤让艾丽斯对亲密接触产生病态恐惧。
- **方法论的使用**: 中止性接触，从完全自控的非性触碰开始分级重建安全感，每成功一次削弱创伤条件反射。
- **结论**: 渐进暴露让恐惧源在受控条件下脱敏。
- **结果**: 艾丽斯恢复安全感，与吉姆订婚。作者将此法直接类比到交易者的"分级暴露"（从小仓位/模拟开始面对恐慌场景）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 明确知道该止损但"下不了手"，每次拖到亏更多。
2. 害怕隔夜持仓/不敢重仓/恐惧某一类行情，理性知道该做却做不到。
3. 开市前心里没底、焦虑，需要一套"心理热身"流程。
4. 之前有过一次大亏创伤（如某次暴跌割肉），导致对该场景过敏。
5. 想用模拟/小仓位逐步面对恐惧场景（渐进暴露）。

### 语言信号 (用户的话里出现这些就应激活)

- "我怕止损，每次都不舍得砍"
- "隔夜持仓我很慌"
- "最坏情况来了我该怎么办"
- "开市前心里没底"
- "I can't pull the trigger" / "scared to take the loss" / "rehearse the worst case" / "pre-market anxiety"

### 与相邻 skill 的区分

- 与 `stop-loss-discipline`：本 skill 训练**面对止损时的心理承受力**，后者给出**止损规则本身**（三分法/保本）。两者组合：先有规则，再预演执行。
- 与 `state-shifting`：本 skill 是**事前预演**（开市前在脑海排练），后者是**事中换挡**（盘中改变环境/姿势）。不抢调用。
- 与 `emotional-temperature-gate`：本 skill 训练"预演恐惧"，后者管理"当前状态"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确要预演的"最坏场景"**
   - 让用户具体描述最怕的交易情境（什么行情、什么触发点、届时自己的反应），写成一幕场景。
   - 完成标准: 场景具体到"可看见画面"（时间、价格行为、自己会做什么）。

2. **预演到无停顿（核心训练）**
   - 指导: 闭眼、深呼吸、在脑海完整播放该场景（含自己的恐惧反应和应对动作）；中途不适→暂停→平静→继续。
   - 完成标准: 用户能在脑海中无停顿播放完整流程（可多次练习达成）。
   - 判停条件: 若用户多次预演仍强烈生理不适（心跳剧增、呼吸急促）且无法继续 → 改用"渐进暴露"：先从更小的场景（模拟盘、小仓位）开始，分阶段靠近。

3. **把预演变成开市前的例行热身**
   - 设定: 每天开市前固定时间做 5–10 分钟"放电影"，内容包括最坏情形+应对动作。
   - 完成标准: 用户有固定的预演时段，且明确"预演内容包含止损/离场动作"而非只预演盈利。

4. **（可选）升级为真实小仓位分级暴露**
   - 若用户对某场景过敏，建议用最小真实仓位/模拟盘反复面对，逐步扩大。
   - 完成标准: 有一条"从哪级开始、多久升一级"的暴露计划。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有止损规则/交易计划——先有规则再预演，否则预演的是"没有计划地恐慌"。
- 严重创伤（如经历崩盘爆仓后的创伤后应激障碍）——需要专业心理治疗，不是自我预演。
- 用户想要的是"积极想象成功"的自我暗示——方向相反，本 skill 预演**最坏**情形。

### 作者在书中警告的失败模式

- **预演利润而非止损**（ce09/ce20）：作者"最糟糕的交易以粗略估算潜在利润开始"——预演内容必须是应对（止损/离场），不是幻想盈利。
- **浅尝辄止**：压力预防的效果取决于使用频度与强度，做一次不坚持等于没做。
- **"消除恐惧"误区**（ce10）：不是压抑恐惧，而是预演到它不再劫持行为。

### 作者的盲点 / 时代局限

- 脑海预演依赖想象力，对"图像化想象能力弱"的人效果打折；作者部分案例依赖声光机器/生物反馈等设备辅助（设备方案已过时，可代以现代冥想/手环）。
- 预演脱敏对"条件化恐惧"有效，对"方法本身无效"的恐惧无能为力——若预演后实盘仍亏，问题在方法不在心理。
- 暴露疗法需注意强度阶梯，作者在临床中有人监督；自我暴露时应更保守。

### 容易混淆的邻近方法论

- "积极想象/吸引力法则"——方向相反，本 skill 预演失败与应对。
- "模拟交易积累经验"——那是 `implicit-learning-immersion` 的范畴；本 skill 是心理预演，不是真实市场练习。
