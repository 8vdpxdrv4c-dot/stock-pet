# 三重验证结果 — trading-psychology

> 阶段 1.5 产出。候选池来源：frameworks(23) + principles(58) + cases(40) + counter-examples(20) + glossary(25) = 166 条，去重合并后形成 14 个候选技能单元，全部通过 V1/V2/V3。
> 用户偏好：只做**交易执行/复盘类**，剔除生活通用类（情感多元化等）。

---

## V1 / V2 / V3 说明

- **V1 跨域**: 同一方法论在书中 ≥2 个独立语境（不同章节/不同对象/不同案例）有佐证
- **V2 预测力**: 能回答一个书中没明说的新问题
- **V3 独特性**: 不是任何聪明人都能说出的常识，必须含作者独特视角

---

### v01 大无畏的交易清单 / 一致性复盘
- 来源候选: f04, p01, p02, p16, p58, g05, g06, c01, ce02
- **V1**: 第1章作者自述"五大不一致"复盘 + 第4章"记录日志识别哪个我在交易" + 第14章"记录所有交易及理由/状态/结果" + 第14章原则⑥ 三个独立语境 ✓
- **V2**: novel_question = "我连续三个月稳定亏损，但每笔都有理由，问题到底在哪？" → 用清单逐笔对照成功/失败交易找五个维度的不一致（仓位/准备/执行/角度/清仓），结论通常是方法没问题、执行不一致，而不是策略错 ✓
- **V3**: 普通复盘记盈亏，作者复盘记"一致性缺口"——反常识（工具与智力无法替代一致性）✓
- 支撑案例: c01（作者五不一复盘）、c02（苏的拼图）、c08（64位交易者尽责性）
- → 进入阶段 2
