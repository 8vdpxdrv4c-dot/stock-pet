# 市场元信息：怎么走，比走到哪更重要

## R — 原文 (Reading)

> 股市就像人一样，处理的是信息交流和元信息交流。股市的信息交流是它在时间中的动作：三周上涨了10%，过去一小时跌了5点，等等。股市的元信息交流描述了股市做出这些动作的方式：循序渐进的还是突然的，高成交量还是低成交量，波动大还是小，大部分股票参与还是不参与，等等。我们所说的行业分析在很大程度上是指努力读懂股市的元信息交流。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第6章

> 想象两个相似的五分钟条形图……股市的信息交流都是一样的，但股市的元信息交流却绝不是一样的。……这种无效（效率低）是一个很重要的元信息交流。它意味着最初的趋势正遭遇严重的破坏。效率下降之后通常是趋势改变。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第6章

> 期望猛然落空是股市最重要的元信息交流之一。当股市没有做应该做的事情时，就表明市场正在变化。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第6章

## I — 方法论骨架 (Interpretation)

交易者只看"涨了/跌了多少"（信息），作者要求再加一层：**市场是怎么做到的**（元信息）。把市场当"说话的人"，不仅要读它说的内容（价格），更要读它说话的语气（节奏、量能、广度、效率）。四条元信息信号：

1. **效率**：一段行情"走过的距离"vs"走出的路径长度"之比。直线行情=高效（健康趋势）；来回震荡=低效（趋势被破坏）。"效率下降之后通常是趋势改变"。
2. **广度**：指数涨是否伴随大部分股票涨。只有少数股票参与的上涨（如 40 只股票假突破案例）= 脆弱趋势。
3. **期望落空**：市场没有做"应该做的事"时，是最重要的变化信号（如该涨不涨、该跌不跌）。
4. **同步性**：相关市场/板块不同步（如商品与股市背离、共同市场没同步动作）——异常即元信息。

作者甚至用"积极缺失预示消极即将出现"（抑郁症前兆的类比）说明：**市场积极信号的缺失本身就是信号**。解读元信息的失败="无视元信息去做交易，就和网恋一样，没有多大胜算"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 40 只股票假突破
- **问题**: 指数创新高，但只有 40 只股票真正突破。
- **方法论的使用**: 读广度元信息——突破缺乏广泛参与。
- **结论**: 广度不足的突破是假突破，趋势脆弱。
- **结果**: 元信息解读避免追高假突破。

### 案例 2: 效率下降→趋势改变
- **问题**: 两个五分钟图都从 A 涨到 B，但一个平稳一个震荡。
- **方法论的使用**: 用"路径长度 vs 净位移"衡量效率——震荡图的效率低。
- **结论**: 效率下降是"最初的趋势正遭遇严重破坏"的信号，之后常伴随趋势改变。
- **结果**: 把效率当作趋势健康的仪表盘。

### 案例 3: 期望落空 = 最大信号
- **问题**: 市场该做某事（延续趋势/突破）却做相反或什么都不做。
- **方法论的使用**: 记录市场"应该做什么"，观察是否落空。
- **结论**: "期望猛然落空是股市最重要的元信息交流之一"——该涨不涨就是变化前兆。
- **结果**: 期望落空被用作转势预警。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到"指数创新高但多数股票没涨"，想知道是真是假。
2. 担心假突破/被突破陷阱骗进场。
3. 想知道趋势是否健康、何时该离场。
4. 复盘时发现自己"只看涨跌不看方式"。
5. 想系统学习如何解读市场语言。

### 语言信号 (用户的话里出现这些就应激活)

- "指数涨了但个股不涨，什么情况"
- "这波突破是真是假？"
- "怎么判断趋势健不健康"
- "背离怎么看"
- "market breadth" / "divergence" / "false breakout" / "is this trend healthy" / "how the market is moving"

### 与相邻 skill 的区分

- 与 `contrarian-pinball-edge`：元信息解读是**读懂市场方式**，逆向交易是**利用市场方式**（在失败突破初期反向）——元信息是逆向交易的输入。
- 与 `internal-observer-emotion-data`：本 skill 读**市场**的语言，后者读**自己**的情绪数据——两者都是"读信号"，对象不同。
- 与 `implicit-learning-immersion`：本 skill 提供解读框架，后者提供把解读练成直觉的路径。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把用户的问题翻译成"信息 vs 元信息"**
   - 让用户说出当前市场"做了什么"（信息），再追问"怎么做到的"（元信息：节奏/量能/广度/同步性）。
   - 完成标准: 写出两条并列描述：信息（涨跌数值）+ 元信息（涨跌方式）。

2. **逐项检查四条元信息信号**
   - 效率: 这段行情是直线还是反复震荡？
   - 广度: 指数/龙头变化有没有多数标的参与？有没有背离？
   - 期望落空: 市场有没有做出"应该做"的事？
   - 同步性: 相关市场/板块是否同步？
   - 完成标准: 每条信号给出"健康/警示"判断和依据。

3. **给出解读结论与行动倾向**
   - 综合信号得出"趋势健康度"结论（如：效率下降+广度不足=趋势破坏预警）。
   - 完成标准: 一个明确的判断（健康/预警/危险）+ 对应的行动倾向（持有/减仓/观望）。
   - 判停条件: 若用户只想要"买还是卖"的断言 → 说明本 skill 提供解读不提供点位，建议用户用自己的系统落地下单。

4. **建立"每日元信息记录"惯例（可选）**
   - 建议用户每天收盘记一条"今日市场的元信息"（怎么走的），累积模式识别经验。
   - 完成标准: 用户同意开始记录，并明确记录什么字段。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是具体买卖点/选股——本 skill 是解读框架，不替代交易系统。
- 用户的问题是情绪/心理（止损执行不了、复盘）——那是其他心理 skill 的范畴。
- 用户没有任何行情数据/图表习惯——元信息解读需要观察习惯作基础。

### 作者在书中警告的失败模式

- **无视元信息**："无视元信息交流去做交易就和网恋一样，没有多大胜算。"
- **死板解读技术指标**：作者批评"机械地解释图表和震荡指标，完全不考虑相关背景"——同样的形态在不同背景（上涨后 vs 暴跌后）含义完全不同。
- **只看"做到什么"不看"没做到什么"**：积极缺失（如该创新高却不创新高）本身就是信号。

### 作者的盲点 / 时代局限

- 元信息概念移植自人际沟通心理学，转用于市场是一种隐喻——市场无意图，解读本质是交易者的建构。
- 作者基于日内/指数期货经验（TICK 等），不同市场/品种的等效元信息指标不同。
- "期望落空"依赖交易者的预期设定——预期本身可能偏差，需结合统计验证。

### 容易混淆的邻近方法论

- "技术分析/画线"——本 skill 读的是**市场行为方式**，不是形态预测。
- "消息面/基本面"——本 skill 是价格行为的元层面，与基本面无关。
