# 交易计划 = 船锚：说出来 + 假设检验 + 先锋头寸

## R — 原文 (Reading)

> 交易计划就是你的船锚，当波涛涌动时，你迫切希望使用它。在制定和执行交易计划时，任凭股市波涛汹涌，保持行为目标明确，你就能够控制自我、把握股市。对付贪婪和恐惧的心理良药不是冷静，不是自信，而是行动目标。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第2章

> 在开车上班的路上，我会说出我的评论，我会说出我能想到的每一项意外：如果开市走低，我会这样做；如果市场回转并创下新高，我的计划是这样，等等。关键在于，要以平时说话的声音大声说出来，就好像你在跟另一个人说话。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第2章

> 他们总是先买入小额头寸来投石问路，情绪不会过早受到牵制。如果预测是正确的，那么以后还有足够的时间来大展身手；如果预测不正确，损失也不会太大。我把最初的这些小额头寸叫作"先锋头寸"，用它们来"勘察地形"。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第11章

## I — 方法论骨架 (Interpretation)

盘中失控的本质是"在情绪高潮时临时做决策"。交易计划把决策提前到清醒时做完，盘中只负责执行。作者的三件套：

1. **大声说出计划（客观化）**：开市前以"对另一个人说话"的方式把计划说出来——描述趋势、发现的模式、预期入市点、适当退市点，并说出每一项意外预案（开市走低怎么办、创新高怎么办）。说出来后一人分饰说话者与倾听者，从客观视角审查计划；计划里的错误在没交易前就被否定。作者原话："许多交易者太害怕错过可能出现的市场行情，以至于他们不敢花时间不断关注交易计划"——恰恰是忽略计划带来更大风险。
2. **每笔交易=科学假设**：第5章把交易当作可证伪的假设——入场理由、预期、证伪条件（触发即离场）。配合 `stop-loss-discipline` 的三分法止损。
3. **先锋头寸勘察地形**：不确定时先买小额头寸"投石问路"，情绪不被过早牵制。预测正确→后续大展身手；预测错误→损失可控。避免"没头没脑进入市场=在爱情中冲昏头脑"。

作者强调：**对付贪婪和恐惧的良药不是冷静，而是行动目标**——计划本身就是情绪的解药。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者开车上班路上的自言自语
- **问题**: 盘中情绪高涨时会偏离计划。
- **方法论的使用**: 早晨锻炼后，开车上班路上大声说出当天计划与每一项意外预案。
- **结论**: 说出来后一人分饰两角，从客观角度审查计划；错误在交易前就被否定。
- **结果**: "一旦你把交易计划说出来，许多内容就会留在你的脑海里"——盘中更能坚持。

### 案例 2: 先锋头寸投石问路
- **问题**: 交易者想下大赌注，担心判断错误。
- **方法论的使用**: 先买小额头寸勘察地形，确认后再加仓。
- **结论**: 小头寸=低成本验证假设；情绪不被过早牵制。
- **结果**: 预测正确时后续加仓，预测错误时损失可控。

### 案例 3: 场外直到优势出现
- **问题**: 交易者忍不住频繁交易。
- **方法论的使用**: 第4章主张"没有明显优势就在场外"——把"不交易"也写进计划。
- **结论**: 计划不只是"做什么"，也包括"不做什么"。
- **结果**: 等待优势成为纪律的一部分。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 盘中总被临时消息、突发新闻、情绪带跑。
2. 开市前不知道要准备什么，临时起意交易。
3. 计划写得出来但执行不了（需要"说出来"的客观化）。
4. 犹豫要不要重仓一个判断——想用先锋头寸先验证。
5. 不知道"不交易"也是计划的一部分。

### 语言信号 (用户的话里出现这些就应激活)

- "盘中我总是被带跑"
- "开盘前我应该准备什么？"
- "我的计划执行不下去"
- "要不要先小仓位试试？"
- "plan the trade" / "trade the plan" / "I get distracted during market hours" / "scout position"

### 与相邻 skill 的区分

- 与 `stop-loss-discipline`：本 skill 是**整个计划的构造与坚持**，后者是**止损这一个部件的规则**。两者组合：计划包含三分法止损。
- 与 `fearless-trading-inventory`：本 skill 设计**未来计划**，后者审查**历史执行**——先有计划，复盘才有意义。
- 与 `implicit-learning-immersion`：本 skill 把计划**说出来**（显性化、客观化），后者通过**大量练习**内化技能——计划需要练习来巩固执行。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **构造当日计划模板（书面）**
   - 引导用户写出：交易的市场/品种、看好的方向与理由（假设）、入场点、止损点（价格/指标/时间）、利润目标、仓位。
   - 完成标准: 一份 5–10 行的成文计划，含假设 + 证伪条件。
   - 判停条件: 若用户说不出交易假设/入场理由 → 提示没有假设的计划不是计划，建议先观察（场外）。

2. **大声说出计划（客观化练习）**
   - 让用户用"对另一个人说话"的方式，把计划逐条说出来，包括意外预案（开市走低/走高/横盘分别怎么做）。
   - 完成标准: 用户能流利说出完整计划 + 至少 2 个意外预案；说完后自我审查，找出其中的薄弱点。
   - 提示: 说明"对付贪婪和恐惧的良药不是冷静，而是行动目标"——计划就是解药。

3. **应用先锋头寸规则**
   - 若用户对某判断信心不足 → 建议用最小头寸先开，验证后加仓。
   - 完成标准: 用户明确"什么情况下先用先锋头寸、验证到什么程度才加仓"。

4. **把"不交易"写进计划**
   - 与用户约定：没有明显优势/看不清时，计划就是"今天不交易"。
   - 完成标准: 用户接受并写出"场外条件"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有自己的交易系统/方法——计划需要建立在某个方法之上。
- 用户的问题是止损执行（那是 `stop-loss-discipline`）。
- 用户在盘中情绪激动当刻——先处理状态（`state-shifting`），冷静后再做计划。

### 作者在书中警告的失败模式

- **害怕错过而忽略计划**：作者指出许多交易者"太害怕错过行情，不敢花时间关注计划"——忽略计划会带来更大风险。
- **没头没脑进场**：像在爱情中冲昏头脑，表达主观愿望却忽略客观环境——先锋头寸正是解药。
- **只做不说的计划**：闷在心里的计划经不起客观审查——说出来是客观化的关键动作。

### 作者的盲点 / 时代局限

- 作者是职业日内交易者，计划模板针对他的短线节奏；中长线/低频交易者需要调整频率与粒度。
- "大声说出"的客观化效果依赖自我审查能力，作者未量化其有效性。
- 先锋头寸适合情绪易受牵制者，但对已有成熟仓位框架的交易者可能过度保守。

### 容易混淆的邻近方法论

- "写个交易计划"的常识——关键不是写下来，而是**大声说出来 + 写假设 + 有证伪条件**。
- "计划赶不上变化就随机应变"——作者主张用预案覆盖变化，而非放弃计划。
