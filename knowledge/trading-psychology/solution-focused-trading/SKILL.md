# 聚焦解决方案：从特例中找成功模板

## R — 原文 (Reading)

> 重视解决方案的策略之所以有效，是因为它将人的现有勇气作为杠杆，用它来轻松解决原本难以解决的问题。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第1章

> 本书将反复探讨这个主题：问题是失效的解决方案。问题就是在人生某个阶段某种情绪下学会的、而现在本身又成为问题的解决模式。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第1章

> 找出已经存在的有益模式，并学着有意地进入这一模式，便是实现心理转换的最快方式之一。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第14章

## I — 方法论骨架 (Interpretation)

大多数"自我改进"默认一种路径：找到问题、挖出根源、修复缺陷。这套方法反着来。

核心判断有两个：
1. **问题是失效的解决方案**——你现在戒不掉的坏习惯，很可能在过去某个阶段是有效应对（比如熊市里学会的"逢跌就买"曾让你赚钱），只是行情变了、它从优势变成了缺陷。所以不要"消灭它"，而要"替换它"。
2. **答案藏在你已有的特例里**——哪怕一个模式再顽固，你总有不受它支配的时刻（那笔"当时没追高"的交易、那个"没扛单"的下午）。这些例外说明成功的能力已经存在，只是不稳定、没被系统化。

操作方法：去翻自己的交易记录，找出少数执行漂亮、赚了钱的交易，分析当时的状态、时机和方法；把例外提炼成可重复的模板。这比整天盯着错误去克服要快得多——因为杠杆是"你已经能做到的事"，而不是"你做不到的事"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 苏的拼图——解决方案早已存在
- **问题**: 患者苏的生活一团糟，想放弃学业与爱情。
- **方法论的使用**: 作者没有给方案，而是让她完成一张拼图；拼图过程中苏回溯到曾经让生活变好的旧模式（邀请肯尼回家、重返课堂、承担管理责任）。
- **结论**: 她意识到"在我来见我之前，我自己已经启动了解决方案"。
- **结果**: 苏按旧模式重建生活，完成学业。

### 案例 2: 库尔特的高尔夫球思维
- **问题**: 交易者库尔特是完美主义者，交易固执死扛。
- **方法论的使用**: 作者发现他在高尔夫球场能坦然接受失误，于是让他把"高尔夫球场的思维"带进交易——失败交易=失球，接受它、调整、再出手。
- **结论**: 例外时刻（高尔夫）里的成功心态，可以迁移到交易。
- **结果**: 库尔特获得了卖出头寸、再择机买回的灵活性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 反复出现同一个坏交易习惯（追高、扛单、报复性交易），"下决心"多次无效。
2. 复盘时只盯着亏损和错误，越看越沮丧、越改越无力。
3. 问"我为什么总是这样"但不想再深挖心理创伤。
4. 有一两笔"自己都没想到能做好"的交易，想弄明白当时做对了什么。
5. 把问题描述成"我这个人就是没纪律"——需要被纠正为"模式失效"而非"人格缺陷"。

### 语言信号 (用户的话里出现这些就应激活)

- "我改不掉这个习惯"
- "为什么我又犯同样的错"
- "我明明知道不该追高/不该扛单，还是做了"
- "复盘都是亏损，越看越丧"
- "can't break this habit" / "I keep repeating the same mistake" / "why do I always do this"

### 与相邻 skill 的区分

- 与 `fearless-trading-inventory`：本 skill 聚焦**例外/成功模板**，后者聚焦**不一致缺口**。实际流程可先跑后者找出模式，再从这里找例外。
- 与 `novelty-change-consolidation`：本 skill 回答"**往哪里改**"（找例外模板），后者回答"**怎么让改变稳固**"（新意→改变→巩固）。本 skill 找到模板后，用后者完成固化。
- 与 `internal-observer-emotion-data`：本 skill 是改变方向的选择，后者是改变期间的自我观察工具——不抢调用。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把"问题"重写为"失效的解决方案"**
   - 让用户描述反复出现的坏习惯，追问: 这个习惯最初是在什么情况下学会的？它当时解决了什么问题？
   - 完成标准: 用户能把习惯说成"曾有效的应对，现在失效了"（而不是"我就是没救"）。

2. **找出 1–3 个例外时刻**
   - 问: 最近有没有一次，你差点又要那样做、但（或没）做了不一样的事？那笔赚钱的交易当时什么状态？
   - 完成标准: 至少找到 1 个具体的例外，能说清"当时的环境/心态/动作"。
   - 判停条件: 若实在找不到任何例外，且用户处于自我否定 → 跳到步骤 1 复查"失效的解决方案"叙述，避免硬挤。

3. **把例外提炼成可复制的模板**
   - 从例外中提取 2–3 条可重复要素（触发条件 + 正确动作），写成一个 if-then 模板。
   - 完成标准: 有一条"当 X 出现时，我做 Y（那个例外里的动作）"的模板，用户确认可行。
   - 提示: 模板固化交给 `novelty-change-consolidation`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题是急性风险（刚爆仓、情绪崩溃）——先止损和稳定，不急着找模板。
- 用户只想要一次具体交易建议（该买还是卖）——这不是本 skill 的职责。
- 用户完全没做过任何成功交易/没有任何例外（纯新手）——例外池为空时，先积累最小样本。

### 作者在书中警告的失败模式

- **只改表象不改模式**（p44）：同一心理病灶会表现为十几种形态，逐一修修补补治标不治本——要找的是潜在模式本身。
- **把问题当人格缺陷**（ce01/ce13）："我这个人没纪律""把投资当恋爱"——需要重写为"失效的解决方案"。
- **聚焦问题而非解决方案**（ce02）：越盯着问题越看不见自己已经做对的部分。

### 作者的盲点 / 时代局限

- 聚焦解决方案在"有成熟经验/有例外"的人身上最有效；纯新手例外池为空，需要先积累样本。
- 案例以心理治疗患者为主（求助者偏差），将其推广到所有交易者需谨慎。
- 不深挖成因的立场可能与需要理解深层原因的复杂问题冲突——若例外反复无法复现，可能需要回到机制层面。

### 容易混淆的邻近方法论

- "积极思维/正能量"——本 skill 不是自我暗示，而是**基于真实交易记录的例外提取**。
- "行为矫正"的奖惩法——本 skill 依赖用户已有的成功模式，不是外部奖惩。
