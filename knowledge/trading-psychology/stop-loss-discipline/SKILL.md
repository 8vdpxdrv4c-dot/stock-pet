# 止损纪律：三分法止损 + 失败是成本

## R — 原文 (Reading)

> 通常，这些止损规则可以分为三类。（1）基于价格的止损规则；（2）基于市场指标的止损规则；（3）基于时间的止损规则。基于时间的止损规则……是我最喜欢的止损规则……如果我的头寸在接下来的5小时内没能达到目标利润水平，不管价位如何，我会坚持平仓。对我来说，这是最理性的止损了，因为这说明我研究出的市场优势不复存在了。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第3章

> 在成功的交易者中，我曾多次注意到一种思维定式：他们把失败的交易看作做生意的成本。棒球选手很清楚，只要有60%的击中率，他们就能步入名人堂。……从心理上来说，尽管他们可能屡次失败，但他们从未内化失败的体验。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第11章

## I — 方法论骨架 (Interpretation)

止损执行不了，从来不是"缺勇气"，而是**止损规则没有预先写死**，临时决定时情绪才有机会插手。作者的三分法把止损变成可预编程的规则：

1. **基于价格的止损**：按固定价位/支撑阻力位触发。最常见的止损，但作者最不喜欢——价格区域（尤其标准普尔、纳斯达克期货）经常出现虚假突破，容易被打掉。
2. **基于市场指标的止损**：按市场指标触发（如 TICK 综合指数两小时均线、TIKI、指标背离）。更接近市场本质，可用作止损也可用作获利目标；恐慌抛售/买入的极端时点也是好止损点。
3. **基于时间的止损**：作者的最爱——预设时间窗口（如 5 小时），到时无论价位平仓。理由：**时间到了还没走出预期 = 你研究出的市场优势不复存在**，这是最理性的止损，因为它直接检验"假设是否成立"。

配套的两个心态转换：
- **止损=假设被证伪**：每笔交易是科学假设，止损是假设检验失败的离场信号，与"我失败了"无关。
- **失败=生意成本**：成功的交易者不内化失败体验——像棒球名人有 60% 击中率，重点不是单次失手，而是"尽早分辨哪些是赔本的买卖并及时遏制"。

若止损后情绪仍痛苦，用 `stress-inoculation-rehearsal` 预演止损场景；若反复止损后复盘，用 `fearless-trading-inventory`。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者的 5 小时时间止损
- **问题**: 判断"未来 5 小时市场将下跌"并卖空，但走势平稳没到目标利润。
- **方法论的使用**: 用时间止损——5 小时到时无论价位平仓。
- **结论**: "走势平稳"本身是市场走强的信号，时间止损让交易者能反向思考（调查向上突破的可能）。
- **结果**: 时间止损成为作者最喜欢的退出策略——直接检验研究优势是否还在。

### 案例 2: 75 美元死扛的失败模式
- **问题**: 交易者死扛亏损，把短线扛成中线。
- **方法论的使用**: 作者指出遵守止损点的价值；长期打破止损点被比作股票交易者的"12步戒瘾计划"。
- **结论**: 一次两次大亏可以输掉之前偶尔赢来的所有利润；不守止损导致交易溃败。
- **结果**: "止损策略的事前预演"被纳入成功交易者的惯例。

### 案例 3: 棒球名人堂思维——失败即成本
- **问题**: 交易者把单次亏损内化为自我否定，影响后续执行。
- **方法论的使用**: 把失败交易看作做生意的成本，像棒球手接受 40% 的出局率。
- **结论**: 成功交易者"从未内化失败的体验"——止损是筛选赔本买卖的机制。
- **结果**: 失败即成本成为交易者心理免疫的一部分。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 止损执行不了——舍不得砍、死扛、把短线扛成长线。
2. 被套后祈祷反弹，最后割在更低位。
3. 不知道止损该怎么设——想要一套可执行的三分法规则。
4. 止损后心态崩了，觉得"我失败了"。
5. 想知道"保本止损"、时间止损怎么用。

### 语言信号 (用户的话里出现这些就应激活)

- "我舍不得砍仓"
- "止损怎么设？"
- "又扛单了"
- "割肉好痛"
- "my stop loss keeps getting hit" / "can't take the loss" / "how to set stop loss" / "I keep hoping it comes back"

### 与相邻 skill 的区分

- 与 `fearless-trading-inventory`：本 skill 是**止损规则本身**（怎么设、怎么执行），后者是**复盘机制**（为什么总是不一致）。发现"止损总不一致"时，先用本 skill 定规则，再复盘。
- 与 `stress-inoculation-rehearsal`：本 skill 解决"规则缺失"，后者解决"知道规则但害怕执行"——有规则但执行不了，组合预演。
- 与 `trading-plan-anchor`：止损是交易计划的一个部件；本 skill 聚焦止损本身的分类与心理，后者聚焦整个计划的构造与坚持。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判断当前止损是"缺规则"还是"缺执行"**
   - 问用户：你目前用什么规则止损？每次能执行吗？
   - 完成标准: 区分两种情况——无规则（→步骤2）或规则清楚但执行不了（→转 `stress-inoculation-rehearsal` 预演）。

2. **按三分法为用户的品种/系统设计止损规则**
   - 基于价格: 明确的支撑/阻力位或固定金额。
   - 基于指标: 定义触发止损的市场指标（如 TICK、成交量、背离）。
   - 基于时间: 给每类交易预设时间窗口，到时无条件平仓。
   - 完成标准: 为用户的每一类交易写出至少 1 条止损规则，并指定默认用哪种（建议以时间止损为兜底）。
   - 判停条件: 若用户没有交易系统/入场理由 → 先说明"止损必须挂在一个假设上"，没有假设的交易本身不成立。

3. **把止损重定义为"假设被证伪"，做心态转换**
   - 引导用户把每笔交易写成一句话假设 + 对应止损触发条件。
   - 完成标准: 用户能用"假设被证伪"描述止损，而非"我错了"。
   - 配套: 解释"失败=生意成本"，让用户接受单笔止损是成本不是失败。

4. **固化执行（可选组合）**
   - 若用户"知道规则但怕执行" → 建议与 `stress-inoculation-rehearsal` 组合，开盘前预演止损被触发。
   - 完成标准: 用户有一个可重复执行的止损触发清单 + 预演安排。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有入场依据/交易系统——止损必须锚定假设，没有系统谈止损是空谈。
- 用户止损后情绪崩溃、需要的是复盘与心态修复（`fearless-trading-inventory`）。
- 用户问的是"哪个价位止损好"的具体技术答案——本 skill 给框架，不给点位。

### 作者在书中警告的失败模式

- **最不喜欢价格止损**（原因：假突破频繁打止损）——除非叠加指标/波动率调整。
- **打破止损点会累积溃败**：一两次大亏足以输掉此前所有胜利（如 75 美元死扛案例）。
- **时间止损被忽视**：作者称之为"最理性的止损"，因为它直接检验研究优势是否还在。

### 作者的盲点 / 时代局限

- 作者是短线/日内交易者，时间止损在日内最适用；对中长线交易者，时间窗需要重新设计。
- 基于指标的止损依赖作者的 TICK/TIKI 数据经验，其他市场/品种需自行寻找等效指标。
- "失败即成本"的思维定式有道理，但作者没有给出仓位-盈亏比的整体框架（如凯利准则）——止损纪律需要配合仓位管理。

### 容易混淆的邻近方法论

- "保本止损"——这只是止损的一种形态（把止损移到成本价），不是独立的体系。
- "越跌越买/补仓"——与止损纪律相反，作者主张尽早识别赔本买卖并遏制。
- "止损=承认失败"——作者重新定义为"假设被证伪"，止损是科学流程的一部分。
