# 逆向交易的弹球窍门：找到设计之外的规则

## R — 原文 (Reading)

> 读大学的时候，我靠玩弹球机打发时间……过了一段时间，我终于在一台弹球机上发现了一个小窍门：一个可以得分的特殊门道。于是，我反复利用这一窍门赢得高分。……有趣的是，只有采取那些看起来奇怪的、不合常理的策略时，才有可能发现窍门。如果采用设计者事先设计好的方式来打弹球或电子游戏，结果必然失败。……要想在市场中获胜，你只需要找到一个这样的窍门，不断重复使用即可。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第11章

> 在市场最疲软的时候（如5%的股票创新低），是买入的好时机。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第11章

> 一次大赢可能导致你疯狂地预期，并导致你冒更大的风险……一个教训是要理解市场的变化无常。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第11章

## I — 方法论骨架 (Interpretation)

绝大多数人"按设计师设定的方式"打市场：追突破、追热点、追共识。但弹球机的经验是——**只有在违反直觉、不合常理的策略中才能发现窍门**，设计师给大众设定的玩法注定失败。

作者将市场比作弹球机，主张：
1. **找到隐藏的窍门**：一个反复出现、可重复利用的市场规律（他举的例子：在两侧斜坡布局——让球自主弹跳而非强制控制；篮球电子游戏的角落投篮高命中率）。关键是"找到一个窍门，不断重复使用即可"。
2. **逆向方向**：作者用"5% 股票创新低"研究说明——在市场最疲软、最恐慌时买入，常是反转机会；同理"在市场最狂热时谨慎"（过度自信研究）。
3. **去除情绪、机械化执行**：弹球窍门成功的关键是"除去了情绪干扰，整个游戏几乎机械化、程式化"——不确定性减少正是策略成功的主因。

作者提示"动量生命周期"（第14章原则⑨）：趋势在生命早期惯性延续、后期衰竭反转——逆向交易在趋势衰竭的初期进入。同时，"理解市场的变化无常"（一次大赢可能导致疯狂预期）要求逆向者不被自己的成功冲昏。

## A1 — 书中的应用 (Past Application)

### 案例 1: 弹球机的斜坡窍门
- **问题**: 作者弹球水平一般，按常规打法无法高分。
- **方法论的使用**: 发现"任球从斜坡滚下击中左挡板→必能右挡板击中→反弹到得分区"的机械规律，反复利用。
- **结论**: 反常策略才能发现窍门；机械化执行去除情绪干扰。
- **结果**: 一次投币玩一整天；并将此心智模型迁移到交易。

### 案例 2: 5% 股票创新低的逆向研究
- **问题**: 市场恐慌到 5% 的股票创 52 周新低，多数人不敢买。
- **方法论的使用**: 在市场最疲软时买入。
- **结论**: 极端恐慌常常是反转的起点（有统计支撑的反向指标）。
- **结果**: "最疲软时买入"成为逆向交易的可重复规则。

### 案例 3: 失败突破的初期反向
- **问题**: 突破经常失败（作者在多个案例中观察假突破，如 40 只股票假突破）。
- **方法论的使用**: 识别失败突破的初期阶段，反方向交易。
- **结论**: 大众在突破时追入，逆向者在突破失败初期反向。
- **结果**: 元信息信号（广度不足）→ 逆向机会。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 追突破总被套，想换一种思路。
2. 市场恐慌到极点，想知道该不该"反着买"。
3. 想寻找自己市场的"隐藏规律/窍门"。
4. 别人都在追某个热点，自己觉得"太拥挤"。
5. 想建立一套逆向交易规则（什么时候反着做）。

### 语言信号 (用户的话里出现这些就应激活)

- "追突破总是被套"
- "别人都在买，我是不是该反着来"
- "市场恐慌到极点了，能买吗"
- "这个规律靠谱吗，能反复用吗"
- "contrarian" / "trade against the crowd" / "buy the panic" / "failed breakout" / "everyone is chasing this"

### 与相邻 skill 的区分

- 与 `market-meta-communication`：元信息提供**识别信号**（广度不足=假突破），本 skill 提供**行动方向**（反向利用）——元信息是逆向交易的输入。
- 与 `trading-plan-anchor`：逆向也是计划的一部分——"5% 创新低就买"这种规则要写进计划并机械化执行。
- 与 `emotional-temperature-gate`：一次逆向大赢后可能"疯狂预期、冒更大风险"——大赢后的亢奋状态正是"状态不对不交易"要拦住的时刻。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把用户的情境翻译成"大众玩法 vs 潜在窍门"**
   - 让用户描述当前市场的主流做法（大家在做什么：追突破？恐慌割肉？），并写下"如果我反着做会怎样"。
   - 完成标准: 明确大众行为 + 一个反直觉的候选策略。
   - 判停条件: 若用户只想"反着来"但没有任何候选规律 → 先提示逆向不是永远反着做，需要找到可统计的规律。

2. **验证候选窍门的可重复性**
   - 引导用户用历史数据检验候选策略（如 5% 创新低后的表现、失败突破后的反向），至少 20–30 个样本。
   - 完成标准: 候选策略有初步统计支持（胜率/盈亏比/样本量）。
   - 提示: 作者的核心标准是"一个窍门，不断重复使用"——不能重复的直觉不是窍门。

3. **机械化执行（去除情绪）**
   - 把验证过的窍门写成触发规则（什么信号→做什么），尽量机械化。
   - 完成标准: 一条可执行的逆向规则 + 明确的反向退出条件。
   - 配套: 规则要写进交易计划（`trading-plan-anchor`），配合止损（`stop-loss-discipline`）。

4. **预防"大赢后膨胀"**
   - 提示用户：一次逆向大赢后最容易加大仓位、冒更大风险——设置"大赢后主动降仓"的保险。
   - 完成标准: 用户有明确的大赢后降温规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有行情数据习惯/统计能力——窍门必须有数据支撑，不能拍脑袋反着做。
- 用户情绪恐慌中（刚被套）——先处理状态（`state-shifting`），冷静后再设计逆向规则。
- 用户没有交易系统——逆向规则是系统的一部分，不是独立的交易方式。

### 作者在书中警告的失败模式

- **采用设计师设定好的方式**："如果采用设计者事先设计好的方式来打弹球或电子游戏，结果必然失败"——跟随大众共识。
- **忽略变化无常**："一次大赢可能导致你疯狂地预期"——成功是逆向者的最大风险。
- **无样本的反向直觉**：作者的反向策略都有研究/统计支撑（5% 创新低），不是"感觉要反转"。

### 作者的盲点 / 时代局限

- "弹球窍门"本质是统计套利思想的文学化表达，作者未给出如何系统发现窍门的方法论（只有轶事）。
- 5% 创新低等反指标来自作者当时的美股市场环境，其他市场/时代需重新验证。
- 逆向交易在趋势持续超长的行情中会持续亏损（接飞刀）——作者未充分讨论逆向策略的时间成本。

### 容易混淆的邻近方法论

- "每次都要跟大众相反"——作者的观点是**找有统计支持的窍门**，不是无差别逆向。
- "抄底/接飞刀"——本 skill 是"在验证过的极端信号处买入"，与盲目抄底不同。
