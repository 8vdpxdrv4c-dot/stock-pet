# 盲测结果 — state-shifting

## should-trigger-01

- activated_skill: state-shifting
- reason: "一坐交易台就紧张到无法思考"精准命中 state-shifting 核心触发——情绪状态锁死思维，正是"can't think straight"的典型信号；且发生在交易现场、需即时换挡，而非开市前预演。
- if_triggered_action: 引导用户先离席、改变姿势并放慢呼吸节奏，用身体状态的变化打断紧张锁死，重建思考空间后再回到交易。

## should-trigger-02

- activated_skill: state-shifting
- reason: "被套住了、坐不住、脑子一片空白"直接对应 state-shifting 触发器"被套住了/坐不住了/情绪上头"。用户被情绪僵持锁死，当下需要身体换挡恢复思考，而非止损规则或交易复盘。
- if_triggered_action: 让用户立刻离开屏幕，深呼吸或起身走动一圈，先把"空白"的身体状态重置，再回来处理仓位决策。

## should-trigger-03

- activated_skill: state-shifting
- reason: "盘中心跳加速、怎么冷静"是典型的身体状态与情绪绑定失控场景。心跳加速属于身体信号，skill 核心正是用呼吸与身体动作反向调节身体状态，进而让情绪降温。
- if_triggered_action: 引导做缓慢深长的呼吸并站起来活动，用身体节奏放慢带动心跳与情绪回落，待稳定后再继续交易。

## should-not-trigger-01

- activated_skill: stress-inoculation-rehearsal
- reason: "开市前预演最坏情况"正是 stress-inoculation-rehearsal 的核心动作——开市前闭眼在脑海中反复"放电影"预演最坏情境；state-shifting 的不适用项也明确把该场景移交预演类技能。
- if_triggered_action: 指导用户开市前闭眼深呼吸，从止损被触发到暴跌在脑中完整放电影，直到无须停顿地播完全程以脱敏。

## should-not-trigger-02

- activated_skill: NONE
- reason: 长期失眠加焦虑属于身心健康与医疗范畴，不属于交易现场的情绪状态锁死问题。没有明确的交易触发器与状态绑定场景，强行套用任何交易心理技能都不合适。
- if_triggered_action: 不激活技能，先表达关切并建议就医/睡眠干预渠道；若后续回到具体交易状态问题，再重新评估。

## edge-01

- activated_skill: state-shifting
- reason: 该问题直接触及 skill 核心机制——用呼吸节奏改变身体状态进而调节情绪。紧张时询问深呼吸是否有效，正是想学习"换挡"技术的信号，处于技能适用边界之内。
- if_triggered_action: 先简述"身体-情绪绑定"原理，再现场演示并让用户实践一次深呼吸，亲身体会状态变化，作为换挡技术的入门练习。
