# 触发器识别 → 消极自我对话 → 交易教练

## R — 原文 (Reading)

> 结果发现，触发器是最大的交易破坏者。……许多时候，你不能识别哪些触发器在起作用，但却可以认清紧随其后的消极的自我对话。这种自我对话有点儿自动的、照本宣科的味道……辨识出磁带的内容是你抛开它们的第一步。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第10章

> 在"交易教练"训练中，你将以教练的角色去培训一个初学交易的人。你的主要工作就是教导你的学生如何成为成功的交易者。把你预期、进入或退出的头寸都设想成你学生的头寸。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第10章

> 对交易者而言，用日记记录自我对话是有益的训练之一。内心交谈是主动的我（I）与受动的我（me）之间的交谈；是你和自我关系的直接测度。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第13章

## I — 方法论骨架 (Interpretation)

破坏性交易行为通常不是一个"决定"，而是三步自动链：

1. **触发器**：一个与强烈情绪事件绑定的刺激（连续亏损、错过机会、新闻、他人的评价、甚至"饱腹感"式的身体线索），一经出现就切换到问题模式。
2. **消极自我对话**：触发器之后自动"播放"的磁带——"我完了""又要爆仓了""我不行"。多数时候触发器本身难认，但这盘磁带可以认。
3. **错误行动**：在磁带驱动下做出的冲动行为（加仓翻本、追高、扛单）。

干预从**辨识磁带**开始：把自动话语写下来、命名、与之拉开距离。然后用"**交易教练**"替换：把将要执行的头寸设想成"你的学生"的头寸，以教练的口吻对这个学生说话——你会怎么鼓励他止损？怎么教他不要追高？大多数人对自己说话的方式，如果发生在他人之间就算感情虐待。

这个链条把"我要改变"落成三个可执行动作：识别触发、点名磁带、以教练身份替换。核心洞察：**你识别不了触发器没关系，你总能识别那盘磁带**。

## A1 — 书中的应用 (Past Application)

### 案例 1: 琼的白大褂——用自我对话切换自我
- **问题**: 暴食症患者琼是儿童心理治疗师，能治愈患者却管不住自己。
- **方法论的使用**: 作者让她在家穿上白大褂，用"治疗患者琼"的口吻对自己说话——把治疗师的自我移植到自身。
- **结论**: 你做不到的事，用"你信任的那个人"的口吻就能做到。
- **结果**: 琼停止暴食与催吐，形成全新自我形象。此法=交易者的"交易教练"模板。

### 案例 2: 交易者甲丙的触发器图谱
- **问题**: 交易者甲经历1987年崩盘后对正常下跌过敏；交易者丙对交易刺激"上瘾"，平静就无聊。
- **方法论的使用**: 作者总结触发器的类别——创伤型（崩盘记忆）、刺激依赖型（交易当娱乐）、获利兴奋型、错失焦虑型。
- **结论**: 大量非理性交易是下意识规避触发器的结果。
- **结果**: 治疗方法不是意志力，而是先识别触发器、再设计远离触发器的执行环境。

### 案例 3: 玛丽的"外公录音带"
- **问题**: 玛丽在亲密关系中不断重复童年受虐形成的模式。
- **方法论的使用**: "暂停"规则——觉得不对劲时喊停，问自己是"真实的自己"还是"外公录音带"在反应，把愤怒对准录音带而非关心的人。
- **结论**: 给自动磁带命名，就能与之拉开距离。
- **结果**: 玛丽最终结婚；此法被作者直接迁移为交易策略（识别内在录音带，用假设检验替代）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在特定情境下反复失控（亏损后加仓、兴奋后追高），自己也觉得"像变了一个人"。
2. 事后骂自己"我怎么会那样做"，但下次照旧。
3. 交易时脑子里自动播放消极声音（"我完了""又要亏了"）。
4. 想打断一个根深蒂固的自动化行为习惯。
5. 复盘时只能归因于"情绪上头"，找不到具体原因。

### 语言信号 (用户的话里出现这些就应激活)

- "我一亏就上头/控制不住"
- "每次错过机会我就想追高"
- "我脑子里有个声音一直在说我不行"
- "怎么打断我这个习惯"
- "I get triggered" / "I lose control after a loss" / "negative voice in my head" / "can't stop myself"

### 与相邻 skill 的区分

- 与 `internal-observer-emotion-data`：本 skill 处理**具体的触发器→磁带→行动链**，后者是更基础的**观察能力**（泛化的情绪即数据）。辨识磁带依赖观察能力——若用户连情绪都觉察不到，先补后者。
- 与 `emotional-temperature-gate`：本 skill 是"打断已触发的模式"，后者是"事前判断要不要交易"——组合为"先测温挡住不该做的交易，触发后打断模式"。
- 与 `novelty-change-consolidation`：本 skill 提供打断旧模式的**即时动作**，后者提供改变后的**固化机制**。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别触发器**
   - 让用户回顾最近 2–3 次失控时刻，寻找共同点（时间、行情、持仓状态、身体感受）。
   - 完成标准: 写出 1–3 个具体触发器（"连续两笔亏损后""持仓浮盈回撤时"）。

2. **点名消极磁带**
   - 问: 触发之后，你脑子里自动播放的那句话是什么？让它原样说出来。
   - 完成标准: 得到一段"磁带内容"原文（如"我又要亏光了，我不适合交易"），并给这盘磁带起个名字（如"恐慌磁带"）。
   - 判停条件: 若用户识别不出任何磁带/触发器（情况更模糊）→ 用日记记录一周自我对话（`p42`），下周转回来。

3. **以教练身份替换磁带**
   - 引导: 把当前头寸设想成"你的学生"的头寸——你会对那个初学交易者说什么？把这段话写下来。
   - 完成标准: 产出一条"教练台词"，用户确认它比原磁带更有建设性。
   - 提示: 可以用磁带的原话当"触发词"，一出现就启动教练台词。

4. **设计远离触发器的环境（可选强化）**
   - 若能识别触发器，建议环境改造（止损单自动执行、限制交易时段、资金隔离）。
   - 完成标准: 至少 1 项环境改动落地，减少触发器被激活的频率。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是"心情不好想聊聊"——没有明确触发器链，不适用。
- 急性危机（刚爆仓、情绪崩溃、自伤）——需要稳定与支持。
- 问题根源于方法无效而非心理模式——触发器训练不能替代有效策略。

### 作者在书中警告的失败模式

- **触发器是最大交易破坏者**（ce14）：甲乙丙丁四类触发器图谱——识别是治疗的第一步，忽略就是持续失血。
- **消极自我对话=自我虐待**（ce19）："我真是个废物"式的自我对话若发生在他人之间算感情虐待——用日记记录自我对话会发现惊人的时间浪费。
- **"是的，但是……"麻痹**（ce19）：用借口无限期推迟决策——教练角色正是为了打破这种拖延。

### 作者的盲点 / 时代局限

- 触发器概念源自条件反射心理学，作者用它解释交易者自动行为，但部分案例（琼、玛丽）属深度心理治疗场景，自我应用时的强度与安全性无法照搬临床。
- 触发器识别的可靠度依赖自我报告，加扎尼加"解释器"研究提示人可能编造动机——需用日志交叉验证。
- "交易教练"角色对需要权威引导的人效果显著，对自我批判过强或过弱的人需调整语气。

### 容易混淆的邻近方法论

- "情绪管理/深呼吸"——本 skill 的关键是**识别链条并替换磁带**，不是泛泛的平静练习。
- "自我激励"——教练台词是**具体指导性**话语（教学生怎么做），不是"加油你能行"。
