# 情绪温度测量：状态不对不交易

## R — 原文 (Reading)

> 要在有目的的行为和情绪激动之间建立联系，一个重要的步骤就是周期性地测量你的情绪温度。白天，人的情绪会在情绪低落（无聊、冷漠）和情绪高涨（焦虑、热情）之间摇摆。他们也会从相对积极的状态转向更加消极的状态。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第3章

> 一旦你注意到自己的认知、身体和情绪状态，根据医生的信条，你的首要目标就是"无论如何，避免伤害"。如果你觉得无聊，情绪低落，那么不要交易。……在进入市场之前，你需要等待自己进入正确的思维模式。任何思维分散、思想不集中都是在告诉你有东西出了差错。
>
> — 布雷特·斯蒂恩博格，《投资交易心理分析》第3章

---

## I — 方法论骨架 (Interpretation)

情绪温度不是"心情好不好"的比喻，而是一套可量化的二维测量：

- **激发水平**：无聊/冷漠 ↔ 焦虑/热情（你有多"热"）
- **效价方向**：积极 ↔ 消极（你的基调是正还是负）

交易前和交易中定期"读温度"，把它当作是否交易的闸门。核心规则是"先无害，再盈利"：
- 无聊 → 容易不假思索做短线（作者自己的失败模式）
- 情绪低落 → 别交易
- 过度兴奋/亢奋 → 警惕、别追单
- 焦虑 → 容易过度谨慎或冲动止损

把身心状态作为交易的**正式组成部分**——像等行情一样，等自己进入正确的思维模式再交易；任何思维分散都在告诉你"有东西出了差错"。

它把"情绪管理"从玄学变成可操作的自检清单：测量 → 判断状态是否适合交易 → 不合适就退出/缩小仓位/离开屏幕。与内部观察员配套：先有旁观者才能测量。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者的无聊冲动交易
- **问题**: 低波动市场令人百无聊赖，作者忍不住做短线"缓解无聊"。
- **方法论的使用**: 复盘发现"无聊→行动"的失败模式，建立情绪温度测量，把状态写入交易决策。
- **结论**: 无聊时做的日内交易很少盈利。
- **结果**: 此后作者只在情绪温度处于适宜区间时交易。

### 案例 2: 面对市场压力离开屏幕
- **问题**: 市场新奇变化让人天然感情用事。
- **方法论的使用**: 在有压力和不确定性时暂时离开交易屏幕，休息间歇快速更新指标、以全新角度看待数据。
- **结论**: 离开屏幕=给自己一个"冷静期"，避免亢奋中仓促决策。
- **结果**: 心情沉寂下来后，才能认清市场的真实环境。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 开盘前/交易中问"我今天该不该交易？"
2. 明显处于异常情绪状态仍想开仓（无聊手痒、亢奋追高、低落硬撑）。
3. 连续亏损后心态失衡，但还想"翻本"。
4. 想建立一套"状态自检→决定是否交易"的例行流程。
5. 复盘时发现"状态不好的时候交易几乎都亏"。

### 语言信号 (用户的话里出现这些就应激活)

- "今天适合交易吗？"
- "我状态不太好但想交易"
- "太无聊了想找点交易做"
- "刚赚了一波，现在很兴奋"
- "should I trade today" / "I'm not in the right mood" / "bored, want to trade" / "too excited to trade"

### 与相邻 skill 的区分

- 与 `internal-observer-emotion-data`：本 skill 是**测量与闸门**，后者是**观察机制**。本 skill 的测量依赖观察员能力；若用户还没有观察能力，先补后者。
- 与 `state-shifting`：本 skill 判断"**是否**该交易"，后者解决"**如何**把状态换回来"。本 skill 判定状态不对后，可用后者换挡；换不回来就离场。
- 与 `fearless-trading-inventory`：本 skill 是**执行前的实时闸门**，后者是**复盘时的历史审查**。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **测量当前情绪温度**
   - 让用户按 0–10 分别给"激发水平"（无聊0↔亢奋10）和"效价"（消极0↔积极10）打分，并说出身体信号（心跳、肌肉、呼吸）。
   - 完成标准: 得到两组数字 + 一句身体状态描述。

2. **对照危险状态清单做判断**
   - 对照: 无聊(激发≤3)、低落(效价≤3)、亢奋(激发≥8)、焦虑——任一命中 → 判定"状态不适配交易"。
   - 完成标准: 给出明确建议：交易 / 暂缓 / 离场，并说明依据哪个读数。
   - 判停条件: 若用户处于亢奋/焦虑且坚持要交易 → 先执行 `state-shifting`（离开屏幕/踱步/换环境）再重新测量；二次测量仍高 → 明确建议今天不交易。

3. **建立"状态自检"例行流程**
   - 帮用户设定: 开盘前 1 次、每交易时段 1 次、情绪波动时即时 1 次的测量节奏，并记录结果。
   - 完成标准: 用户有明确的自检时刻表和"命中危险状态时的行动"（离场/缩小仓位/暂停）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是具体买卖点、止损位、市场方向——本 skill 只回答"状态允不允许交易"。
- 用户状态测量连续正常但持续亏损——问题可能在方法本身，转 `trading-personality-match` 或方法审查。
- 急性情绪危机（刚爆仓、崩溃）——先稳定，再谈测量。

### 作者在书中警告的失败模式

- **情绪化=忘记规则**（ce08）：情绪一起规则就被忘——闸门的价值是把规则前置。
- **心境依赖**（ce06）：赢钱后过度自信、输钱后过度谨慎——情绪温度正好拦截这两种状态下的交易。
- **把"心态好"当骄傲**（ce10）：拒绝承认焦虑→用胶带遮仪表盘——测量要求诚实面对读数。

### 作者的盲点 / 时代局限

- 自我报告的情绪测量受主观性影响，作者也提到生物反馈（可穿戴设备测心律/皮肤电）可提供更客观的读数，但设备方案已过时，可用现代手环替代。
- 二维模型（激发×效价）是简化，真实情绪更复杂；测量只是门槛，不是全部决策依据。
- 对"状态好时才交易"的解释也可能循环论证——状态变化既可能是结果而非原因（见阶段0批判）。

### 容易混淆的邻近方法论

- "心情不好就别做"的常识——本 skill 要求**量化测量 + 明确规则**，不是随口感受。
- "情绪管理"的泛泛建议——本 skill 给出可执行的自检清单。
